# 🚀 SuperStore Sales Analysis | Power BI Dashboard

An interactive **Power BI dashboard** designed to analyze sales performance, profitability, customer segments, and shipping trends using the SuperStore dataset.

This project transforms raw data into meaningful business insights through interactive visualizations and key performance indicators (KPIs).

## 🎯 Project Objectives

- Analyze overall sales, profit, and quantity sold.
- Compare year-over-year performance between 2019 and 2020.
- Identify top-performing product categories and subcategories.
- Analyze customer segments and payment preferences.
- Evaluate shipping modes and delivery performance.
- Track monthly sales and profitability trends.

## 📊 Key Performance Indicators

| Metric | Value |
|---|---:|
| 💰 Total Sales | $1.6M |
| 📦 Total Quantity Sold | 22K |
| 📈 Total Profit | $175K |
| 🚚 Average Delivery Time | 4 Days |

## ✨ Dashboard Features

- **Sales Analysis:** Track revenue and identify sales trends.
- **Profit Analysis:** Monitor profitability and monthly performance.
- **Product Analysis:** Compare categories and subcategories.
- **Customer Segmentation:** Analyze Consumer, Corporate, and Home Office segments.
- **Shipping Analysis:** Explore sales performance across shipping modes.
- **Payment Analysis:** Understand customer payment preferences.
- **Year-over-Year Analysis:** Compare business performance between 2019 and 2020.
